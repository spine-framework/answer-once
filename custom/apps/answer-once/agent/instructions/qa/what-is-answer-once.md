## Q

What is Answer Once?

## A

Answer Once is a support and knowledge app built on the Spine Framework.
The idea is that no question should have to be answered twice: you ask a
question, and if we already know the answer you get it instantly with a citation
to the published knowledge article. If we don't know it yet, a human resolves
it — and that resolution is reviewed and published so the next person gets the
answer automatically.
